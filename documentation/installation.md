# Installation and deployment

## Requirements

To browse the delivered template: a modern browser. To rebuild or test: Node.js 20+ and npm. The delivery uses HTML5, CSS3, Bootstrap 5.3.8 CSS and vanilla ES6+ JavaScript. Bootstrap JavaScript is unnecessary because navigation and controls use the template's accessible vanilla implementations.

## Local preview

1. Open a terminal in the project folder.
2. Run `npm install` once if development dependencies are missing.
3. Run `npm start`.
4. Open `http://127.0.0.1:4173/pages/index.html`.
5. Stop the preview with Ctrl+C.

Direct `file://` opening also works: shared HTML is already embedded, scripts and fonts are local, and no runtime fetch is used. Browser privacy settings may limit localStorage for local files; the theme remains usable for the current page.

## Static deployment / GitHub Pages

Upload `index.html`, `pages/`, `assets/`, favicon files, `robots.txt`, `sitemap.xml` and the relevant documentation. Keep the directory structure. Asset URLs use `../assets/` from pages and work beneath a repository subdirectory. Configure GitHub Pages to serve the project root. Do not upload `node_modules`, `.npm-cache`, test artifacts or development-only scripts.

`pages/404.html` is the designed error page. GitHub Pages requires a root `404.html` for automatic unknown-route handling: copy the generated page to the root and adjust its `../assets/` references to `assets/` and its page links to `pages/...`. Other hosts can route their 404 handler to `pages/404.html`. The included preview server returns HTTP 404 for missing resources with a link to that designed page.

## Metadata

Search for `https://example.com/table-and-tale` and replace it with the production base URL in `scripts/build.cjs`, then rebuild. Update sitemap and robots together. Do not publish sample phone numbers, addresses or event dates as verified facts. WebPage JSON-LD intentionally avoids fake business, review or inventory claims.

## Reproducible build

`npm run build` renders all eleven pages and detail-route templates and copies the local Bootstrap stylesheet. `node scripts/brand.cjs` recreates the SVG identity. `node scripts/fetch-fonts.cjs` refreshes locally hosted Google Fonts and requires internet access. Original generated images are delivery assets and are not regenerated by the build.
