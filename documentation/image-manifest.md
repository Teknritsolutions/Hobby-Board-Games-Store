# Image and identity inventory

66 original locally stored WebP photographs/product views, generated separately with the built-in ImageGen tool and optimized with ImageMagick. All images retain their aspect ratio; page layouts crop with object-fit where appropriate. Hero assets load eagerly; below-fold images use lazy loading.

Each game has different catalog, detail, related-game and finder images. Seven additional homepage product shots and one game-of-the-week scene are included. A zoom dialog displays the selected detail photo at a larger size; it is intentionally the same photograph rather than a new content image. Related product routes use the same related-game asset for the same product identity.

Two extra event photos are supplied as optional library assets. They are not repeated in live page content.

## Brand assets

- `assets/icons/logo-primary.svg`, `logo-light.svg`, `logo-dark.svg`: primary horizontal and theme variants.
- `assets/icons/logo-mark.svg`: compact dice/tile mark.
- `favicon.svg`, `favicon.ico`: root favicons.
- `assets/icons/favicon-16.png`, `favicon-32.png`: PNG icons.
- `apple-touch-icon.png`: 180 × 180 touch icon.
- Error and maintenance illustrations: distinct inline SVG compositions in the respective HTML pages.

## Generation provenance

See `image-prompts.json` for the generation prompt set and `image-inventory.json` for dimensions, byte counts and SHA-256 hashes. All checksums are distinct. Generated originals remain in the development machine's Codex generated_images folder; optimized deliverables are self-contained in this project. No third-party images are hotlinked.
